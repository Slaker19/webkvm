# WebKVM v0.1.14-fix01

Patch release on top of v0.1.14. Same binary line as `main` at `4c76a49`.

## Fixed

- **App Store deploy dialog lies per-appliance** (Council r6):
  - Deploying OPNsense (or any of the 8 cloud-init-less appliances: pfSense, IPFire, VyOS, OpenWrt, HAOS, TrueNAS, OMV) no longer asks for cloud-init user/password — those credentials were silently discarded and the box booted with its vendor default login (`admin/opnsense`). The backend now refuses such a deploy with `400` instead of dropping the input.
  - Disk-image appliances (cloud OS, NAS, router/firewall — 26 entries) can no longer be deployed as Incus LXC containers; the dialog shows a fixed KVM target. The backend defaults an untyped deploy of these to KVM, rejects container deploys without a base image (`400`) and fails loudly (`503`) when Incus is not installed.
  - The catalog notes (default logins, RAM floors, installer quirks) are surfaced inline in the deploy dialog.
- **Frontend UI version is now baked from the git tag** on every build path (Makefile, Dockerfile, release workflow); a CI guard fails the build if the bundle does not carry the tag version. v0.1.14 shipped with the UI reporting 0.1.13.
- **In-app updater on source-mode hosts**: a source update (`REPO_DIR` is a git checkout) on a host without Go/Node is refused with a clear `503` before the 202, instead of dying on `npm: command not found` while the UI reported "updating".
- **Release ship gate**: the embedded frontend bundle must hash-match the freshly built `frontend/dist`, so a binary can never ship with a stale UI again.

## Catalog download links repaired

- VyOS: pinned nightly deleted upstream (404) → current 2026.11.22 rolling.
- pfSense CE: `nyifiles.pfsense.org` mirror dead; 2.8+ requires the Netgate Installer → last freely downloadable full image (2.7.2, 576 MB) on the official `atxfiles.netgate.com` mirror.
- OpenWrt: new `openwrt-25.12` entry on the current 25.12.6 stable (23.05 is EOL; existing installs keep the still-downloadable old entry).
- Source whitelist gained `atxfiles.netgate.com`, `pkg.opnsense.org` and the `vyos/vyos-nightly-build` GitHub prefix — builtin URLs that failed the whitelist made admin edits of those entries impossible.

## Upgrading

Native installs update from `/#/status` (the backend requires `WEBKVM_ALLOW_UPDATE=1`; SHA256SUMS verified, `webkvm.previous` kept, health-checked with rollback). Docker pulls `slaker1908/webkvm:latest`.
